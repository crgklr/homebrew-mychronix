# Homebrew tap for Mychronix

[Mychronix](https://github.com/crgklr/mychronix) for Apple Silicon Macs:

```sh
brew install --cask crgklr/mychronix/mychronix
```

`brew upgrade` brings each new version. The cask is updated by Mychronix's
release workflow; changes made here by hand are replaced at the next release.
